개인정보처리방침

Search Demand Map · 시행일 2026년 9월 17일

1. 접근하는 Google 사용자 데이터

  • Google Ads API(https://www.googleapis.com/auth/adwords 범위)를 통해 개발자 본인의 Google Ads 계정에서 키워드 월간 검색량(Keyword Planner 과거 측정항목)만 읽습니다.
  • 광고, 캠페인, 결제, 잠재고객 등 다른 계정 데이터는 읽거나 수정하지 않습니다.
  • 이 도구는 일반 사용자에게 배포되지 않으며, 개발자 본인의 계정만 연동합니다.

2. 데이터 사용

  • 조회한 검색량은 검색어 군집의 크기를 계산하는 데만 사용합니다.
  • 결과는 개발자의 컴퓨터에 정적 파일(JSON, HTML)로 저장됩니다.

3. 저장과 보안

  • OAuth 토큰과 조회 결과는 개발자의 로컬 컴퓨터에만 저장되며 외부 서버로 전송하지 않습니다.
  • 토큰은 Google 계정 설정에서 언제든 접근 권한을 철회해 무효화할 수 있습니다.

4. 제3자 공유

  • Google 사용자 데이터를 제3자에게 판매, 공유, 이전하지 않습니다.
  • 광고 목적으로 사용하지 않습니다.

5. 데이터 삭제

  • 로컬 저장 파일을 삭제하면 모든 데이터가 제거됩니다.
  • 삭제 요청이나 문의는 아래 이메일로 보내 주세요.

6. Google API 서비스 사용자 데이터 정책 준수

이 도구의 Google API 사용은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

Privacy Policy (English)

Search Demand Map uses the Google Ads API (scope adwords) solely to read monthly keyword search volume (Keyword Planner historical metrics) from the developer's own Google Ads account. It does not read or modify ads, campaigns, billing, or audience data. OAuth tokens and results are stored only on the developer's local computer, are never sent to external servers, and are never sold or shared with third parties. Delete the local files to remove all data. The use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements.
