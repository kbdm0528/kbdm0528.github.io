Search Demand Map

검색어 자동완성과 검색량 데이터를 묶어 "사람들이 무엇을 찾는지"를 군집 지도로 보여주는 개인 연구 도구입니다.

무엇을 하는 도구인가

  • 씨앗 키워드 하나로 Google·네이버 자동완성 검색어를 수집합니다.
  • 문장 임베딩으로 비슷한 검색어를 군집으로 묶고, 군집마다 수요 집단과 설명을 붙입니다.
  • Google Ads Keyword Planner와 네이버 검색광고 API의 월간 검색량으로 군집 크기를 정합니다.
  • 결과는 정적 HTML 지도 한 장으로 저장됩니다.

Google 계정 연동에 대해

  • Google Ads API는 키워드의 월간 검색량(Keyword Planner 과거 측정항목)을 읽는 데만 사용합니다.
  • 도구는 개발자 본인의 컴퓨터에서 실행되며, 개발자 본인의 Google Ads 계정에만 접근합니다.
  • 광고·캠페인·결제 정보는 읽거나 수정하지 않습니다.

About

Search Demand Map is a personal research tool that collects search suggestions, clusters them with sentence embeddings, and sizes each cluster by monthly search volume from Google Ads Keyword Planner and Naver Search Ads. It runs locally and only reads keyword metrics from the developer's own Google Ads account.
